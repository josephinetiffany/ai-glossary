AI 讀寫文字時的最小單位，也是計算長度與費用的單位。

🍜 白話比喻

Token 就像樂高積木。大型語言模型沒辦法直接看「一整句話」，它會先把句子拆成一塊塊積木，再用積木來理解和組裝回答。常見的英文單字可能一塊就搞定，少見的字會被拆成好幾塊；中文通常一到兩個字就是一塊。

每個模型能同時拿在手上的積木數量有上限（叫做「上下文長度」），超過了，最前面的積木就會被放下——這就是為什麼聊太久，AI 會「忘記」一開始說過的話。

⚙️ 它是怎麼運作的

  1. 切塊：分詞器（tokenizer）依照事先學好的規則，把文字切成 token。
  2. 變成編號：每個 token 對應一個數字編號，模型實際處理的是這串數字。
  3. 計算與限制：輸入加上輸出的 token 總數，決定了能不能放得下、以及使用 API 時要付多少錢。

💬 實際例子

I love bubble tea

可能被切成：「I」「 love」「 bubble」「 tea」→ 約 4 個 token

我愛珍珠奶茶

中文常被切得比較碎，同樣意思可能用掉更多 token（實際數量依模型而不同）。

⚠️ 常見誤解

  • ❌ 1 個 token = 1 個字。✅ 不一定，要看語言和模型的分詞方式。
  • ❌ 上下文越長，AI 就一定記得越清楚。✅ 放得下不代表都會注意到，重點資訊最好寫在提示詞裡明顯的位置。
